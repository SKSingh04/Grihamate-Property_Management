# Grihamate Property Management

A modern real-estate property management website built with React and Vite.

## Live Website

https://sksingh04.github.io/Grihamate-Property_Management/

## Features

- Responsive real-estate website
- Property listings and property detail pages
- Property image galleries
- Property video/media support
- Contact form with Formspree
- Supabase integration for property media
- Client-side routing with React Router
- Responsive UI with Tailwind CSS
- GitHub Pages deployment through GitHub Actions

## Tech Stack

- React
- Vite
- React Router
- Tailwind CSS
- Supabase
- Formspree
- GitHub Pages
- GitHub Actions
