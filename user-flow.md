# Grihamate — User Flow

## 1. Overview

This document describes the expected journey of a visitor through the Grihamate website.

The primary goal of the user flow is to help visitors:

1. Understand what Grihamate offers.
2. Explore featured properties.
3. Learn about Grihamate's property management services.
4. Understand the company's mission and vision.
5. Contact Grihamate when they have a property requirement.

The initial website is primarily a showcase and information platform. More advanced user flows may be introduced as additional requirements are defined.
